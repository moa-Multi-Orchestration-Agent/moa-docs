# 0001. 실행 엔진으로 LangGraph 사용

- 상태: 채택
- 날짜: 2026-10-13

## 배경
편집기에서 만든 노드 그래프를 실행해야 하며, 승인 노드에서 멈췄다가 재개하고, 워커가 재시작돼도 이어서 실행해야 한다.

## 선택지
1. **직접 만든 DAG 실행기** — 의존성 없음 / 체크포인트·재개·병렬을 직접 구현해야 함
2. **Temporal** — 내구성 최고 / 별도 서버 운영 부담이 학기 범위를 넘음
3. **LangGraph** — 체크포인트·interrupt·병렬 superstep 기본 제공 / LangChain 생태계 의존

## 결정
LangGraph를 쓴다. 승인(HITL)과 재개 요구를 가장 적은 코드로 만족한다.

## 결과
- 노드 실행 로직은 `NodeExecutor`로 감싸 LangGraph 의존을 엔진 패키지 안에 가둔다.
- 장기 실행 작업(시간 단위)이 생기면 Temporal을 다시 검토한다.
