# 설계 결정 기록 (ADR)

중요한 기술 결정을 "왜 그렇게 했는지"와 함께 남깁니다. 결정을 뒤집을 때는 기존 ADR을 지우지 않고 상태를 `대체됨`으로 바꾸고 새 ADR을 씁니다.

| 번호 | 제목 | 상태 |
|---|---|---|
| [0001](./0001-langgraph-runtime.md) | 실행 엔진으로 LangGraph 사용 | 채택 |
| [0002](./0002-python-single-backend.md) | 백엔드 Python 단일 스택 | 검토 중 |

나머지(ADR-03 ~ 10)는 [설계서 3.6.1](../03-design/software-design.md)에 표로 정리되어 있으며, 필요할 때 개별 문서로 옮깁니다.
